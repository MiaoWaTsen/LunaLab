Impactor Inference

The simulator turns an impactor into a crater. This page runs it backwards: given a crater on the Moon, which impactors could have made it, and how likely is each?

🎯 What the crater tells us

How much the observation narrowed each quantity, compared with what we assumed before seeing it (the prior). 100% means pinned down; 0% means the crater says nothing about it.

〰️ The size–speed degeneracy

Each dot is an impactor consistent with the crater. A small fast one and a large slow one dig the same hole, so the answer is a curve, not a point: the crater fixes roughly the energy, not the size or speed separately.
